# Ovarian Cancer Drug Sensitivity Analysis

## Overview
This project explores drug-response patterns in ovarian cancer cell lines using pharmacogenomic data from the Genomics of Drug Sensitivity in Cancer (GDSC) database.
The aim is to investigate drug sensitivity across ovarian cancer cell lines and eventually explore whether molecular characteristics can help explain differences in drug response.

## Objectives
- Explore ovarian cancer drug-response data.
- Identify variation in drug sensitivity across cell lines.
- Analyze drug response using LN_IC50 and Area Under the Curve (AUC).
- Investigate potential relationships between molecular features and drug sensitivity.
- Develop reproducible data-analysis workflows using R.

## Dataset
**Source:** Genomics of Drug Sensitivity in Cancer (GDSC2)

Dataset currently used:
- GDSC2 fitted dose-response dataset
- 41,957 records
- 19 variables

Ovarian cancer subset:
- 1,461 drug-response records
- 34 unique cell lines
- 48 unique drugs
